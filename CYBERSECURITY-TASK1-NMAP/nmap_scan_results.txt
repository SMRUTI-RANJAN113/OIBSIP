SECURITY ANALYSIS OF EACH OPEN PORT
====================================================================

--------------------------------------------------------------------
PORT 135/tcp - MSRPC (Microsoft RPC Endpoint Mapper)
--------------------------------------------------------------------
What it does:
Port 135 runs the Microsoft RPC (Remote Procedure Call) Endpoint
Mapper. It allows a client to ask a Windows machine which port a
particular RPC-based service is currently listening on (things like
DCOM, Exchange, and various Windows management services use this).
It is essentially a "directory service" for other RPC services
running on the host.

Security risk:
- HIGH RISK if exposed externally. Port 135 has historically been
  a major attack vector, most famously exploited by the Blaster
  worm (2003) and used in several DCOM-based remote code execution
  vulnerabilities.
- It reveals information about other services running on the
  machine, which can help an attacker plan further attacks
  (reconnaissance).
- On a properly configured machine, this port should NEVER be
  exposed to the public internet. It is intended for internal
  network / Active Directory communication only.
- Mitigation: Block port 135 at the perimeter firewall, only allow
  it on trusted internal network segments, and keep Windows patched.


--------------------------------------------------------------------
PORT 445/tcp - Microsoft-DS (SMB - Server Message Block)
--------------------------------------------------------------------
What it does:
Port 445 is used by SMB (Server Message Block) directly over TCP/IP
(replacing the older NetBIOS-based SMB on port 139). SMB is the
protocol Windows uses for file sharing, printer sharing, and
inter-process communication between machines on a network.

Security risk:
- VERY HIGH RISK if exposed externally. This is one of the most
  attacked ports in the world. It was the port exploited by the
  EternalBlue vulnerability (MS17-010), which powered the WannaCry
  and NotPetya ransomware outbreaks.
- SMB is also a common target for brute-force login attempts,
  relay attacks (SMB relay/NTLM relay), and lateral movement once
  an attacker is inside a network.
- Like port 135, this should never be open to the public internet.
  It should be restricted to trusted internal networks only, kept
  fully patched, and ideally protected with SMB signing enabled.
